# 🎓 Student Academic Performance Predictor

A Machine Learning web application that predicts student academic performance based on behavioral and academic factors such as study hours, attendance, assignments, participation, sleep hours, and previous grades.

Built using **Python**, **Streamlit**, and **Scikit-learn**.

---

## 🚀 Features

✅ Predict student final grades instantly  
✅ Interactive Streamlit web interface  
✅ Machine Learning powered prediction system  
✅ Simple and clean UI  
✅ Real-time prediction results  

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## 📊 Dataset Information

The dataset includes the following student attributes:

- Study Hours
- Attendance Percentage
- Assignment Scores
- Previous Grades
- Participation Level
- Sleep Hours

Target Variable:
- Final Grade / Academic Performance

---

## 🧠 Machine Learning Model

### Algorithm Used:
- Linear Regression

### Workflow:
- Data preprocessing
- Feature selection
- Model training
- Prediction generation

The model predicts student academic performance based on input parameters.

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/your-username/Student-Performance-Predictor.git
cd Student-Performance-Predictor
```

---

### 2️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

Application will run at:

```bash
http://localhost:8501
```

---

## 🏋️ Train the Model

To retrain the model:

```bash

```
